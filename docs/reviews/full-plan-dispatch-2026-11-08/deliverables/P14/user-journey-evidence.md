# 用户旅程证据（U01/U11）

## 已离线验证（代码层）
- 验证码/重置密码：隔离委托测试证明“消费失败写=0、用途隔离、间隔/失败锁真实生效、SMTP unknown 不盲退重发”。见 `r0l`、`r0l2`。
- 计费口径：加价率原值保留、FREE 查询只读不写库。见 `r08`。

## 未实际验证（ENVIRONMENT_UNVERIFIED）
- 真实浏览器串联：访客→真实场景→登录/注册安全回跳→正确空间→材料预检→报价确认→任务→成果及费用→刷新后历史→下载/复用。
- 余额不足 / 未知结果 / 撤权 / 到期 / 示例路径的真实页面表现。
- 首页虚假声明（“60+ 上线”“提效 300%”）是否清理、登录 redirect 安全校验、报价确认页展示资料接收者/付款方、历史查看下载不重调模型——代码层未在本批次改动，需真实页面回归。

## 使用隔离 API / 假文件
- 所有测试使用虚构材料与假密钥，无真实费用、无真实库写、无真实网络调用。
- 无法安全启动浏览器时，按指令如实标记 `ENVIRONMENT_UNVERIFIED`，不声称“已验证用户留存/付费意愿”。
