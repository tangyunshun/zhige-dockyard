# 原方案决策与真实环境门：不能由AGI填默认值替代

依据：总纲§4/§6/§9、原方案§6/§14。这是完整派发的一部分，不是要求用户现在逐项作答才能开展所有开发。

| 条件 | AGI现在可实现 | 缺决定时保持的状态 |
| --- | --- | --- |
| 首批客户/业务场景与真实能力验收 | 基于现有已公开且有证据能力显示场景、可配置入口、保留意图、诚实空态 | 不擅选一批C编号发布，不拿演示证明真实能力；人工首批验收待完成 |
| 个人会员/企业套餐权益组合、席位/额度叠加 | 清楚展示现行权利来源/期限，配置校验和冲突提示 | 不自行取消购买条件、叠加赠送、改变既有权益；未定新组合不生效 |
| 售价、利润目标、风险准备、税费/手续费口径 | 版本化报价、成本完整性检查、只读测算与未知标记 | 不编毛利率/markup/售价，不把成本价当售价；不可报价则阻断新收费 |
| 平台现金预算、免费/推广/管理员测试预算 | 有限服务端配置模型、原子预留/拒绝、隔离小阈值测试 | 未批准付费预算不放行相关新付费能力；不假设未来收入抵当前开支 |
| 固定价/真实用量结算、BYOK平台服务费 | 保留现有兼容模式与清晰标签，准备规则接口及测试 | 生产真实Token结算硬关闭、BYOK新收费不开，不偷偷补扣 |
| 退款净额/来源规则、补偿、拒付、企业转个人 | 来源计算/差异核查/只读可退预览、安全状态机 | 原人工APPROVE暂停保持；不能发放商业补偿或把企业钱转个人 |
| 订阅到期后额度、历史资料/导出/超额处置 | 按现有批准规则收回新增资格、保留历史事实与可解释状态 | 不清空付费余额/删资料；未定导出/保留期限不擅编 |
| 线下凭证、收款渠道、审批职责 | 原止损接口、可信事实接口校验、待核实展示 | 无证据不入账，不把备注/图片/paid=true当已确认收款 |
| 活动/推荐/试用资格与额度 | 现有资格幂等核验、活动预算框架、明确示例 | 不创推荐奖励/赠送数值、不发真钱或可消费假余额 |
| 运维人员、告警责任、备份/恢复、SLA | 只读健康状态、可审阅runbook、隔离恢复演练脚本 | 不虚称已备份/已恢复/有人值班，不承诺未经批准响应时长 |
| 真实数据库/供应商沙箱/付费/上线 | 离线迁移、条件模拟、假供应商、测试环境流程与发布门 | 不真实执行；列需要的范围/预算/负责人/回滚证据 |

最终报告逐条标：已有批准证据、DECISION_BLOCKED、ENVIRONMENT_UNVERIFIED，附影响哪个动作。没有批准记录就不能标已批准；不能因为界面有开关就自动打开。

原方案中的个人模板、版本差异分析、推荐奖励等是候选产品建议，不是必须全部新建。优先把现有成果下载/历史/再次工作流程做通；未选择的候选能力登记为可选决策，不以“全部实现”之名无限加功能。

代码/离线验证可集中完成；人工业务认可、真实渠道、现金成本和生产发布不能由AGI自签。最终仍需本助手核验工程版本，再由负责人处理其专属决策与真实发布授权。
