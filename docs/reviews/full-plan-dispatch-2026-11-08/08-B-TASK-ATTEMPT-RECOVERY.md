# 第8批给B：R2持久任务与供应商调用安全恢复

开始：5和6交付后；资金接口依A7 contract，未交时先做无依赖任务状态部分，不猜账务实现。依据原§7.4、§9/R2。

## 流程和范围

用户确认材料/范围/费用→稳定任务及各自预算预留→供应商调用attempt→成果验证→结果/用量/费用状态持久化→可查询/下载。关页、超时或重启不会盲目再付一次钱。

可改Studio handler与Open v1 execute共用执行路径、adapter的调用记录/取消接线、现有任务查询，以及管理员模型部署/供应商测试、workspace/user BYO测试、提示词润色等实际调用入口的最小接线。先枚举真实调用点，不能只修一个route。保留F14解析服务、F11成本裁决和现有模型注册表。

## 实现

1. 同一业务任务稳定ID/请求摘要，重复/并发提交不重复创建收费执行；材料/账户/版本不同不能复用旧结果。权限、激活合同与能力、有效输入、预算先于外部调用。
2. task与attempt分开，持久化调用意图、模型部署/版本、报价/预算/资金关联、响应usage和明确结果；敏感原文/密钥不进入日志或幂等摘要明文。
3. 供应商成功、确定未执行、失败、超时未知、取消未确认区分。超时不等于供应商没计费；unknown不盲重发。按适配器确有支持的查询/幂等恢复，无证据则待核实；不虚构供应商可撤销。
4. 成果schema/非空及合同验证后才能成功；结果、usage、费用/恢复状态关联持久化。失败退款不代表供应商退费。调用实际硬参数来自服务端注册表与授权范围，不由浏览器覆盖。
5. 复用B6共享平台成本预算；内部测试、润色、BYO服务成本及-1权益不旁路。用A7资金契约，不在handler另写账务。确定没发送时才按事实释放；unknown保守保留且可恢复。
6. 任务查询/历史下载只读，不触发新模型、重复扣点或恢复写；通知失败不回退已提交事实。现有后台/持久待办足够时复用，不新建外部队列服务或大规模拆handler。

原§4.3的BYO测试地址变更/旧密钥复用也要核验：凭据绑定其已授权部署/目标，修改地址不能把旧key自动发给新目标；沿用服务端出站安全策略，测试只用隔离接收替身，不实际外发秘密。

## 验证和交接

真实Studio/Open等入口的未授权/缺合同/无价/预算拒绝零外部调用；重复/并发、供应商接受后本地超时、崩溃位置、迟到响应、取消未确认、结果不合格、通知失败、查询/下载零模型/零扣费。模型测试与润色等每个入口至少有一次真实路由预算拒绝证据。

测试用假供应商与条件持久化模拟，不真实模型/OCR/费用。交P08状态图、attempt/恢复接口供A11、UI状态契约供B10、精确结果、模型/SQL片段、handoff。保持生产Token硬关闭，不能用启用新收费掩盖恢复问题。
