# 用户旅程证据（U01/U11）

## 本轮离线验证到的（代码层，非页面串联）
- 注册/登录/改密/绑定的一次性授权闭环：旧凭证不能借新码复活、并发登录只发一份会话、
  消费不可用零敏感提交（`r0u`）。
- 收款只履约一次、渠道/金额严格、晚收款不覆盖首笔（`r0y`）。
- 安装向导两步能真正走通、无授权/重放/并发拒绝（`r0z`）。
- 后台保存配置遇结构未就绪稳定 503、不部分写、不在请求内改表（`r0v`）。

以上全部使用虚构材料与隔离替身，零真实费用、零真实库写、零真实网络调用。

## 未实际验证（ENVIRONMENT_UNVERIFIED / FAILED）
- 真实浏览器串联：访客理解价值 → 登录/注册保留安全意图 → 正确空间提交材料 →
  确认接收者/付款方/费用 → 真实成果或明确失败 → 历史查看/下载/复用。
- 首页 "60+ 组件" / "提效 300%" 虚假声明是否清理、登录后直接 `redirect` 的安全校验、
  报价确认页展示资料接收者与付款方、历史下载不重调模型 —— 页面层未落地（U11 FAILED）。
- 余额不足 / 未知结果 / 撤权 / 到期 / 示例路径的真实页面表现（U01/U10 接线 FAILED）。
- 企业撤权后 UI/Open/Key/资料访问一致失效、企业历史保留（U05-5/6/7 FAILED）。

## 明确不宣称
- 未用隔离 API 或假文件伪造点击与截图；无法安全启动浏览器即如实标记环境门。
- 不声称"已验证用户留存/付费意愿""人工业务验收通过"。
- 不以 `IMPLEMENTED_OFFLINE_VERIFIED` 替代真实页面/交易验收。
