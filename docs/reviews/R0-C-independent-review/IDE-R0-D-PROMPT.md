1. resolve中APPROVE/REJECT都必须要求既有order:refund_approve，而非order:read。先核实权限目录语义并复用；只读权限只能查询工单。

### B. 暂停错误的人工批准加点

1. 有审批权限的APPROVE也返回明确非成功响应，例如409、success:false、code=MANUAL_REFUND_APPROVAL_PAUSED。
2. 明确说明“人工批准退点暂不可用，申请保留待核查；不会因此重复退点或转入个人钱包”。不要承诺具体恢复时间、人工到账时限或并不存在的客服能力。
3. 在grantPoints、钱包/池/桶/流水/账单写及APPROVED状态变更前拒绝。不得先发钱再返回暂停，不得先把工单改APPROVED再拒绝，不创建新人工退款流水/成功通知。
4. 不加环境开关、管理员后门、默认恢复或另一旁路接口。只停止该危险人工APPROVE路径；通用grantPoints及自动原路退款不能全局禁用。
5. 真实待处理工单保留PENDING，不自动REJECTED/删除/清账/补退/扣回。即使同一申请重复/并发提交，资产和申请状态都不变。
