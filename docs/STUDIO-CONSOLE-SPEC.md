## 一、 页面流转关系与全局导航定位
 
### 1.1 系统架构门户定位与体验 CTA 规范
组件大厅（`/studio`）是知阁舟坊系统最核心的系统资产“货架与控制中枢”，具有顶级独立应用门户的定位。
- 必须正常渲染系统全局主导航顶栏 `GlobalHeader`，打通其与系统其他独立页面（如首页、解决方案、价格方案、开发者文档等）的无缝跳转。
- 清除一切局部冗余 Header 模块，防范局部头部与全局顶栏产生视觉堆叠。
- **全局工作台体验 CTA 内置**：顶栏最右侧必须正常渲染 **“免费体验工作台”**（未登录态）或 **“进入我的工作台”**（已登录态）的动态 CTA 按钮，支持用户随时流转，优化从货架大厅到实际研发空间的跳转路径。
 
### 1.2 顶通栏：扁平化亮色 Banner 与核心能力标签组
- **单栏扁平化设计**：顶部采用通栏的高级明快知性蓝渐变 Banner（`bg-gradient-to-br from-[#f0f8ff] via-[#e6f0fa] to-[#d9e8f5] border-blue-100`），将原先臃肿的双栏或右侧指标卡结构彻底摒弃，缩减首屏的垂直高度。
- **内容构成**：
  - **顶部**：展示徽章级标签（使用 `<Rocket className="w-3.5 h-3.5 text-[#2b6cb0] animate-pulse" />` 带柔和呼吸动画的矢量图标，代替低端 Emoji，文字为“知阁舟坊 · 全栈开发效能操作系统”）。
  - **中部**：展示愿景标题（“以标准化‘数据契约组件’一键装配软件工程全流程”）及系统定位描述文字。
  - **底部**：集成五个精美小巧的白底圆角能力标签（标书自检 85%+, API生成 3.5倍, 单测对齐 92.4%, 安全审计 99.8%, 契约流转推荐），物理清除所有的 Emoji，统一替换为精细彩色化 Lucide 矢量工程图标：
    - 标书自检：`<Target className="w-3.5 h-3.5 text-blue-500" />`
    - API 生成：`<Zap className="w-3.5 h-3.5 text-amber-500 fill-amber-500/20" />`

## 二、 智阁空间状态控制台与布局自适应 (Workspace Bar)
 
大厅根据用户登录状态采用自适应 SaaS 栅格布局，彻底消除视觉空白。
 
### 2.1 物理删除理念科普卡
物理删除原 aside 栏内冗余的“💡 自动组件选取设计理念”科普卡片，消除信息堆砌。
 
### 2.2 游客态（未登录）货架“全宽拉通”与去 Emoji 升级
当检测到未登录时：
- 完全不渲染 aside 左栏，释放页面宽度。
- 右侧的流水线控制地图、模糊检索栏以及 53 项组件大货架网格卡片容器的宽度类名动态调整为 **`lg:col-span-12` 全宽拉通**，使其呈现出宏大开阔 of SaaS 控制台主视觉。
 
### 2.3 登录态双栏布局与图标彩色化
当检测到已登录时：
- 维持 `col-span-3` (aside) + `col-span-9` (main) 的传统 SaaS 双栏布局。
- **空间状态监视器**：集成切换工作空间下拉菜单，在用户选择目标空间时物理切换并重定向刷新状态。去除了 select option 内代表空间的 Emoji，使文字阅读更加纯净规范。标题前缀替换为带色的 `<Activity className="w-4 h-4 text-[#3182ce]" />`。
- **Token 算力仪表盘**：拉取并解析该空间的算力配额，以环形 SVG 动态进度条呈现。
- **已装配资产树**：将该空间当前绑定的组件按 10 大开发阶段进行折叠/展开呈现。标题前缀替换为带有知性蓝配色的 `<FolderClosed className="w-4 h-4 text-[#3182ce]" />`。树节点阶段图标由 `getStageIcon` 函数统一注入各个阶段 of 专属主题彩色，使资产列表层次清晰。点击已绑定组件名一键直达工作空间 IDE 运行。
 
### 2.4 已装配资产控制台平铺卡片布局与解绑活跃校验
研发布局控制台内的“已装配应用资产”明细抽屉进行平铺布局 and 防呆校验安全升级：
- **卡片式平铺网格与 Inline Style 边框消黑**：已绑定的应用资产采用单行平铺卡片网格布局（`grid grid-cols-1 sm:grid-cols-2 md:grid-cols-3 gap-4`，3个卡片平分整行），卡片圆角固定为 `8px` (`rounded-lg`)。提升内边距为 `p-4`，高度拉升至 `160px`，去除了多余的分割线。卡片在背景上略微加深以增强对比度。为了彻底避免任何全局 CSS 重置将边框覆盖为粗糙黑线的缺陷，明细卡片通过监听 `onMouseEnter` / `onMouseLeave` 事件获取 `hoveredCardId`，并完全通过 **`style={{ borderColor: ... }}`** 行内样式进行最高优先级的边框颜色精细化控制。在 hover 悬浮时支持向上微移 4px（`-translate-y-1`）以及投影显著加深（`shadow-sm hover:shadow-lg`）的立体质感悬停动效。
- **展示数量限制**：最多只显示前 3 个已绑定的组件卡片，节省纵向高度。
- **“查看更多”头置文字链接**：当绑定组件数大于 3 时，物理删除底部的灰色虚线占位卡片。改为在详细拓扑标题栏的右侧渲染蔚蓝色文字链接：“查看更多组件 (剩余 X 项) ->”。点击它一键重定向路由跳转到该工作空间的管理和配置面板 `/workspace/${workspaceId}`。
- **操作区与活跃拦截**：每个组件卡片上集成两个功能操作按钮，按钮内边距放大为 `px-3 py-1.5`，字号大小提升为 `text-[11px]`，且配备有 `1px` 的细微半透明边框描边以增加实体按压点按质感：
  - **立即使用**：圆角 `4px` (`rounded`)，点击跳转到当前工作空间开发调试界面并自动定位加载此组件（`/workspace/${workspaceId}?componentId=${c.id}`）。悬浮 hover 时支持蓝底白字的反色动效。
  - **解除装配**：圆角 `4px` (`rounded`)，允许用户随时自由解除任何已装配组件的绑定，不对其进行拦截限制，以闭环用户极速装配体验。
- **空间切换鉴权与 Cookie 双保险机制**：工作空间下拉切换涉及 `/api/workspace/switch` 物理切换接口。除在中间件中下传 `x-user-id` Request 头之外，后端切换接口进行强壮鉴权防护：首先读取 Header 里的 `x-user-id`；若读取失败，依次读取 `Authorization` 中承载的 JWT 证书并进行校验；若依然缺失，则执行最终双保险降级策略：尝试从浏览器 Cookie 缓存中直接获取登录时前端写入的未加密用户 ID `userId`。三者任一通过，即可判定为登录用户合法访问，从而彻底根治 401 鉴权失效 Bug。
- **空间下拉切换局部静默刷新与双层缓存拉取规范**：为了保证极致的 SPA 用户体验，切换工作空间时，前端严禁使用整页路由重载导致白屏。必须在物理切换接口 `/api/workspace/switch` 成功返回后，完成以下操作：
  1. 使用 `router.replace` 局部无刷修改浏览器地址栏 `workspaceId` 参数；
  2. 同步且立刻调用 `refreshBoundComponents(targetWsId)` 立即替换当前大厅控制台中已装配应用组件列表；
  3. 立刻调用 `refreshUserState()` 重新从后端拉取用户的最新登录态信息与可用空间对象列表，实现毫秒级、免白屏重载的 SPA 局部静默刷新。
  4. **并行加载防闪烁机制**：在父页面加载受限组件与算力配额时，必须将两个异步 API 在同一个 `useEffect` 周期内通过 `Promise.all` 进行并行请求。等两个网络响应均就绪后，同步且批量调用 React 状态设值函数，将多次页面重绘降为 1 次，防止页面产生多次无谓的渲染和闪烁抖动。
- **已装配资产控制台平铺卡片 border 属性消黑隔离与引导装配规范**：明细卡片圆角固定为 `8px` (`rounded-lg`)。为彻底阻断边框重置冲突，明细卡片物理去除 `border` 类名，转而通过 `onMouseEnter`/`onMouseLeave` 挂载 `hoveredCardId` 局部 React 状态，并强制利用 React 行内样式 `style={{ border: ... }}` 属性进行高优先级控制。
  - 未使用卡片背景为精致高雅的乳白色透明 `bg-white/95 hover:bg-blue-50/20`，常规边框为浅灰 `1px solid rgba(226, 232, 240, 0.8)`，Hover 边框为知性蓝 `1px solid rgba(49, 130, 206, 0.7)`。
  - 使用中活跃卡片背景为柔和淡绿色 `bg-emerald-50/30 hover:bg-emerald-50/50`，常规边框为浅绿 `1px solid rgba(167, 243, 208, 0.7)`，Hover 边框为活跃绿 `1px solid rgba(56, 161, 105, 0.8)`。
  - **空装配快捷引导**：若当前空间内已装配组件数清零，在明细抽屉内除展示占位文字外，下方必须提供一个大厂高亮渐变色、圆角 `4px`、带 Lucide 闪电工程图标的 **“立即装配组件”** 动作按钮。点击该按钮后，通过 DOM 接口自动平滑定位并滚动到下方的“双轨工作模式导流板”（锚定元素 `#dispatch-engines`），降低用户引导成本。

## 三、 数据加工流转契约拓扑 (详情侧滑抽屉)
 
点击任一货架组件上的 `立即使用` 按钮，或在非批量模式下点击卡片/列表行的任意空白区，即可滑出 `ComponentDispatcherPanel` 面板。
 
### 3.1 拓扑图节点规范与无 Emoji 物理表达
- 采用深色极客风格卡片设计（`bg-slate-900`），辅以定性 mock 描述。
- **输入极 (Input Source Node)**：呈现输入协议 JSON Mock。物理清退所有的输入载体描述 Emoji，使用纯文字描述。
- **中枢流转核心 (Engine Hub)**：渲染“数据解构”发光指示，PC 端配有渐变流光流动连接动效，横向指向输出极.
- **输出极 (Output Artifact Node)**：呈现输出协议 Mock。物理清退所有的输出成果物 Emoji，使用纯文字描述。
- 拓扑图下方契约基本属性中的普通打勾符号，统一替换为带有蓝色配色的 `<CheckCircle2 className="w-3.5 h-3.5 text-[#3182ce]" />` 矢量图标。
 
### 3.2 商业 ROI 效益横幅
在抽屉内卡片下方渲染高对比度的提效对比组件，以可视化滑轨和高亮粗体字呈现 ROI 指标。效益指示中的闪电 Emoji 被完全清除，替换为带有“效能飞跃”文字后缀的商业说明，实现 100% 去 AI 痕迹。
 
### 3.3 物理去除悬浮 Footer 与“立即使用”核心按钮内置
为了彻底解决底部悬浮操作栏会物理遮挡页面右下角 `ArrowUp` 回到顶部蓝色悬浮按钮的重大设计缺陷：
- **物理删除 Footer**：侧滑抽屉最底部的固定悬浮白条操作栏被彻底清除。
- **“立即使用”按钮内置与统一**：将一键使用核心按钮内置入侧滑面板的表单及分发绑定矩阵内容区域内，文案统一规范为 **`立即使用`**：
  - **游客态内置**：在分发矩阵提示文本下方内置“立即使用”大按钮，点击进行 Toast 提示并直接跳转登录页。
  - **登录态内置**：在部署空间列表的上方增加“一键装配提效行动条”，直观展示当前活跃目标空间，并内置文案为“立即使用”的操作按钮，点击直接执行装配并在 800ms 内重定向跳转载入空间工作 IDE。

## 四、 契约沙箱仿真模拟器 (Simulator)
 
为了让用户无感检验契约的合理性，详情抽屉内集成了**契约沙箱仿真模拟器 (Contract Sandbox Simulator)** 体验。
 
### 4.1 仿真器流转状态机与极客日志
- **Idle (闲置)**：默认状态。展示仿真欢迎语及“启动契约沙盒仿真”按钮。
- **Running (仿真中)**：点击按钮后，进入模拟处理。以 250ms/条的频次向控制台日志终端追加 6 条高专业度日志，配备光标闪烁动效。日志中所有的状态球等 Emoji 前缀被彻底清退，统一升级为标准的 `[INFO]` 与 `[SUCCESS]` 前缀表示。
- **Success (仿真成功)**：日志全部打印完毕，系统绿灯亮起，展开并高亮打印最终 Mock 输出物协议卡片。成功提示文本中的 Emoji 符号被彻底清除，打勾物理文本替换为高档的 `<CheckCircle2 className="w-3.5 h-3.5 text-emerald-500 inline" />` 矢量图标并显示在绿色高亮状态下。
- 每次用户切换查看不同组件时，仿真状态必须自动重置回 `Idle`，防止静态残留。

大厅右侧按 10 大研发阶段进行货架展示。
 
### 5.1 步骤排版与筛选控制条

- **控制地图矢量化与专属彩色配色**：
  - 流水线控制地图的步骤甘特图圆形按钮，物理清除原有的分类 Emoji。

- **货架过滤**：右侧货架根据当前高亮选中的单个步骤，仅检索过滤并平滑展示当前阶段的精品组件卡片。大标题前的精品货架 Emoji 替换为带色的 `<FolderOpen className="w-4 h-4 text-[#3182ce]" />`。
 
### 5.2 开发需求快速检索
- 登录用户在右侧顶栏展示开发需求快速检索控制台，支持输入开发需求关键字（如“标书解析”、“数据库建模”），系统自动过滤检索并置顶高亮最契合的组件。
 
### 5.3 货架卡片与列表点击行为 100% 对齐与动作按钮升级
- **操作逻辑一致性**：在非批量选择模式下，点击整张网格卡片或整行列表项的任何空白无按钮区，均自然拉起 Inspect 侧滑契约抽屉。

- **动作按钮统一重构**：
  - **未登录（游客）**：卡片/列表中提供唯一主操作按钮 **`立即使用`**（带 `Workflow` 矢量图标），点击直接重定向跳转至登录界面。
  - **已登录**：
    - 主操作按钮（填充底色，占比 flex-1）统一文案为 **`立即使用`**，点击立即拉起分发抽屉面板，由用户指定/选择空间进行操作绑定并流转。
    - 辅助操作按钮为 **`装配 / 解除`**，支持用户在货架上直接秒级绑定至当前活跃的目标空间，无需滑出抽屉，满足极速装配体验。
- **彻底清退全站 Emoji 字符**：为了防止界面呈现出低端粗糙的“AI 痕迹”，页面上全面物理清除所有表示分类的 Emoji 字符，全部以大厂严肃级 Lucide 矢量工程图标并注入阶段专属彩色渲染，达到极客风 SaaS 标准。
- **字号底线**：物理扫除所有微缩文字标签。所有文字规格提升至 `text-xs` (12px) 或 `text-sm` (14px)。

## 六、 双轨工作模式：手动浏览与自动文档匹配 (v9.8 新增)
 
为了提供更细致和全方位的全栈效能服务，组件大厅在右侧工作区顶部集成了**一分为二的卡片式分流导流板 (Dual-Track Onboarding Panel)**，提供明晰的通道说明与操作指导，方便用户理解并自由选择最契合的开发检索方式：
 
### 6.1 主动分流导流卡片设计
- **卡片一 (方式一)：自主精细化筛选模式**
  - **定位**：支持根据 10 大研发阶段可视化流水甘特图、分类历史以及关键字进行组件查找。
  - **文案说明**：适合有明确目标、需自主挑选和快捷装配调试的开发场景。
- **卡片二 (方式二)：设计与文档自动匹配**
  - **定位**：支持用户直接上传设计或接口文档（JSON/PDF/TXT等），结合开发描述获取最匹配的组件。
  - **文案说明**：适合快速集成与自动分析匹配组件的开发场景。
- **高亮联动与交互**：
  - 双卡片悬浮支持向上微移动画效果，选中项锁定呈现蔚蓝色微光并高亮显示实心状态标签 `当前使用中`，未选中项在点击时支持平滑转场，将主区切换到对应的处理形态下。
 
### 6.2 手动浏览模式主面板 (Active Mode UI)
- 集成了流水线可视化步骤地图和 53 项组件精品货架。
- 支持用户根据研发阶段的分类直接浏览、过滤、排序，并手动选择组件进行装配与分发。
 
### 6.3 上传文件匹配推荐模式主面板 (Matching Mode UI)
- 通过点击导流板中的方式二卡片进行切换触发。
- **文件上传区 (可选输入)**：用户可点击或拖拽上传任意设计文档、接口定义文件或数据样本（支持 JSON, PDF, TXT, MD, Word 等常用格式，最大 5MB）。文件上传非强制要求，仅作为可选输入配合分析。
- **需求描述区 (强制输入与非规范校验拦截机制)**：
  - 提供带有必填红心 `zg-required` 标识的文本域，供用户输入主要的研发诉求。
  - **规范校验拦截**：物理清退了顶部 Toast 弹窗的提示形式。系统将根据多维度规则对输入进行分析。若检测到任何一项未通过，则判定为**非规范输入**并拦截匹配进程。
  - **行内警告呈现**：校验失败时，输入文本域立即高亮渲染为 2px 厚度的红色边框与淡红背景警告状态，并伴有红色外发光晕圈效果，同时在下方直接渲染高亮红色警告提示。
  - **规范输入示例引导一键填入**：在文本输入域下方提供 3 个符合真实业务场景的胶囊药丸式药丸徽标示例。用户点击示例可以直接将对应规范内容填入文本框中，并自动清除错误拦截状态，降低使用门槛。
  - **实时错误重置**：当用户在警告状态下重新进行文本键入时，红边警告与底部错误文字会立即自动消失，无缝切回常规输入状态。
  - **上一轮分析推荐的实时擦除机制**：为了防止在用户进行第二轮需求检索时残留上一轮匹配结果，只要点击了“开始分析并匹配组件”按钮，系统必须在触发任何检验之前，将上一轮推荐出来的组件卡片列表以及控制台日志终端日志立即清空并擦除，从源头避免逻辑混淆。
- **匹配分析进度分流终端**：
  - 点击“开始分析并匹配组件”启动计算。若系统检测到用户未登录，则直接在顶部展现 Toast 错误提示，并在 1.2 秒后自动将浏览器路由重定向跳转到标准的 `/auth/login?redirect=/studio` 登录页面，实现流程的高效和流畅。
  - **有文件输入流**：如果用户上传了本地文档，进度控制台动态依次打印出各个处理步骤。
  - **无文件输入流**：如果用户未上传文件，仅有文字需求描述，控制台自动切换为纯文本比对进度打印。
- **匹配结果方案**：分析完成后，以 8px 圆角卡片动态展示最契合的 1-2 个组件，显示具体的匹配度以及详尽的推荐理由。推荐卡片内配置了快捷流转动作。

## 七、 协同工作空间 IDE 大盘重构与扁平化美化规范 (Workspace Internal IDE)
 
为了提高空间内部的工作效率并升级视觉质感，对 `/workspace/[id]` 内部页面进行了深度的全栈业务闭环优化和组件去冗余设计。
 
### 7.1 物理清退 MarketModal 组件导入冗余
- 移除空间内独立的“导入”弹窗（`MarketModal`）和侧边栏顶部的“导入组件”快捷键。
- 空间内组件的装配和挑选权力统一回归至大厅中枢（`/studio`）。空间仅负责在本地直接扁平展示和执行已被绑定/允许使用的效能资产。
 
### 7.2 大盘算力面板底部空间操作按钮区
- 为了解决空间管理与升级企业版按钮在顶栏菜单中“不够直观显眼”的痛点，物理清空侧边栏之后，将“空间管理设置”与“升级企业协作版”大按钮直接平铺排布在大盘右侧的“算力配额与空间监控”监控面板的底部。
- **企业协作版**：“空间管理设置”按钮横跨整行（`col-span-2`，宽度 100%），采用高亮知性蓝背景，高亮指引 Owner/Admin 随时前往空间设置页面进行协作人员管理。
- **个人自主版**：底部左侧展示耀眼的高对比度渐变橙色按钮“升级企业协作版”以引导付费，右侧展示常规白底“空间管理设置”按钮，实现两列平铺，醒目且直观。
 
### 7.3 侧边栏物理清退与未装配周期平铺收纳 (Single-column Layout & Capsule Pills)
- **单栏极简拉通布局**：物理清空侧边栏 aside 导航结构及其移动端切换遮罩，工作台大盘过渡到单栏完全拉通平铺的现代化 SaaS 布局，消除视觉拥堵，把用户的操作核心聚焦在中间的执行大盘上，高度更加自由。
- **未装配研发生命周期胶囊标签组平铺**：原本侧边栏底部的未覆盖阶段胶囊标签组，改在主页面“已装配效能组件快捷通道”大卡片网格的下方进行平铺渲染。所有未覆盖的周期阶段以灰色药丸胶囊（如 `📄 商机打单 +`、`🧪 测试质量 +`）在网格底部水平展列。当检测到未覆盖阶段时，点击胶囊可一键携带当前空间 ID 与阶段参数跳转大厅。
 
### 7.4 工作台主大盘横向进度流转轴与已装配快捷启动网格 (Bento Dashboard Redesign)
- **10 大研发生命周期横向进度流转轴 (Stage Timeline)**：位于主面板顶部最显眼位置的横向 Timeline 进度流转轴。通过渐变连线贯穿 10 大节点：已覆盖阶段节点实心发光，未覆盖阶段细边虚化，鼠标 hover 显示阶段详情与已装配数量，点击可一键跳转大厅装配，提供全局高频联动。
  - **多组件选择悬浮气泡**：若用户点击的 Timeline 节点阶段已装配绑定了多个组件，严禁系统默认直接运行第一个组件。必须在节点下方弹出一个高雅的悬浮小气泡点选面板，列出该阶段的全部组件名称，由开发用户手动挑选对应的具体组件类型后，再完成运行流转，以支持同阶段多组件的科学点选。
- **已装配效能组件快捷通道大卡片**：主面板左侧主体区域重绘并复活“已装配效能组件快捷通道网格”。每一个绑定的效能组件均以独立的毛玻璃轻感白底卡片渲染，高亮呈现其 `输入 -> 输出 契约流向`（如 `PRD 文档 -> 结构化脑图`）、组件功能描述，以及绿色发光“运行中”脉冲微标。用户在主页面内即可直观阅读数据流并一键点击启动运行，大幅提升操持感。
  - **搜索实时联动**：快捷卡片网格实时联动顶栏 Header 里的“搜索组件...”模糊检索框。用户在检索时，网格卡片将实时过滤筛选；若无符合条件组件，则在大卡片网格区域展示友好空状态提示，并提供“一键清除搜索条件”功能。
- **算力 Token 与角色监控仪表盘**：采用知性蓝到高亮绿的发光滑轨，展示剩余算力与空间版型、用户角色快照。
  - **个人自主空间**：算力余额处强悍渲染为 `无限制 (免消耗)`，进度条 100% 极光色充满，角色卡片强制映射显示为 `👑 所有者 (Owner)`，并物理清退多人群组图标。
  - **企业协作空间**：展示真实的 Token 余额和使用进度比率；根据其实际岗位分配显示 `Owner / Admin / Member`，仅在协同成员时显示多人图标。
- **最近数据仿真处理审计流 (Activity Audit Log)**：增加日志面板，模拟展现该空间近期运行组件的提效成效，支持图形化流线图节点展示，提升商业 ROI 说服力。
- **提效三步极速开发路径**：将新手导航和三步极速提效卡片重新排版，与审计日志流并列渲染，极具高密度 SaaS 科技感。
