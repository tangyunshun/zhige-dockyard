## 🎯 1. 优化目标与定位
重构并精简工作空间中枢（Workspace Hub）控制台，消除冗余组件与过度营销感，使其聚焦于对个人空间与企业空间的高效调度、全生命周期管理（升级、分享、加入、创建、一键重置、注销、重命名）及权限审计：
1. **彻底去重与双态导航**：
   - 移除无谓的直达与重复入口。
   - 实现**双态自适应全局导航**：登录工作台路由后自动切换为 `空间中枢`、`组件大厅`、`我的任务`、`企业管理` 和 `开发者文档` 专用导航。
2. **黄金比例 Bento Grid 布局 (左 70% 右 30%)**：
   - 采用 `grid-cols-1 lg:grid-cols-10` 排版。
   - 左侧 7 列渲染空间核心管理， FeaturedComponents（更名为推荐组件）降级底置，只保留最核心的资产管理。
   - 右侧 3 列渲染配额、安全审计折叠切换（默认只看 1 条最新日志，支持一键展开更多）及快捷工具。
3. **解释文案与权限隔离**：
   - 增加个人空间/企业空间的定位定位短文案。
   - **四级角色前端权限隔离**：根据 Owner、Admin、ComponentAdmin、Member 动态配置操作按钮及下拉项，限制越权操作。
4. **V6.0 UI 样式与字号一致性**：
   - 恢复 V6.0 黄金圆角规范：外围大卡片对齐唯一真理的 **`rounded-[20px]`** 磨砂质感；内部小卡片、进度条及按钮对齐 **`rounded-lg` (8px)**。
   - 统一按钮高度：一律固定为系统大气的 **`h-[38px]`**，字号一律固定为系统主字号 **`text-sm font-semibold` (14px)**。
   - 消除字号杂乱：摒弃 ad-hoc 写入的 `text-[9px]`/`text-[10px]`，统一按照系统级 16px (标题) / 14px (正文/按钮) / 12px (标签/辅助) 进行排版。
   - 恢复粒子底图 `radial-gradient(#cbd5e1 1px, transparent 1px)`。

## ⚙️ 4. 核心功能实现逻辑

### 4.1 企业空间四级前端权限隔离
* 卡片载入时解构 workspace.role：
  - `isOwner` (所有者)：次按钮显示“管理成员”；更多菜单内呈现组件授权、空间设置、使用统计、以及高危红色项“解散企业空间”。
  - `isAdmin` (管理员)：次按钮显示“管理成员”；更多菜单呈现组件授权、使用统计。
  - `isComponentAdmin` (组件管理员)：次按钮显示“组件管理”；更多菜单呈现使用统计。
  - `isMember` (协同成员)：不显示次按钮；更多菜单只包含“查看协同成员”、以及高危红色项“退出企业空间”。

### 4.2 跨空间组件装配弹窗 (SelectWorkspaceModal)
* 点击推荐组件卡片时，page.tsx 统一拦截并获取可用空间：
  - 如果无可用的个人或企业空间，提示先开辟/加入空间。
  - 如果只有 1 个可用空间，直接跳转装配页面。
  - 如果有多个可用空间，唤起磨砂背景的 `SelectWorkspaceModal`。弹窗圆角对齐 20px，内部选项列出所有可选空间，用户点选后跳转。
