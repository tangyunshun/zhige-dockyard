# 工作空间中枢（workspace-hub）精简化与重命名功能开发计划

> 日期：2026-06-15
> 状态：等待用户确认

---

## 1. 目标与定位
重构并精简 `workspace-hub` 控制台的页面布局，彻底消除由于不合理的元素堆叠产生的空旷留白；删除与“空间中枢”定位不契合的高阶组件库、微信QQ安全绑定等冗余逻辑，使其聚焦于对个人与企业协作空间的集中呈现和管理操作（升级、分享、加入、创建、扩容、注销、重命名），并结合美观、高科技感的综合实时数据统计面板。

## 2. 界面与布局重构
* **一栏通与两行流 Bento Grid**：
  * **第一行**：
    * **Card 1 (8 列) 极客名片**：精简安全绑定与工坊直达链接，展示头像、名字、邮箱及会员徽章。
    * **Card 2 (4 列) 算力消耗与 Quota**：保留算力消耗百分比圆环和本月 Token 详细数值，保持紧凑高度。
  * **第二行**：
    * **Card 3 (8 列) 工作空间管理中枢**：主卡片。内置 Tab 分栏，列表内支持“进入”、“重命名”、“分享”、“升级/扩容”、“注销”。卡片底部常驻虚线邀请码加入栏。
    * **Card 4 (4 列) 综合数据统计看板**：由原 Card 6 气泡（累计调用、活跃组件、响应时间、成功率）与 SVG 律动趋势图合并组成，高度与 Card 3 自动拉平，消灭空旷留白。
* **Footer 优化**：不保留控制台的大块 Footer，仅在页面最底部居中保留一行低调版权字样 `知阁·舟坊 © 2026` 紧贴下边缘。

## 3. 功能开发：空间重命名
* **前端状态**：
  * `showRenameModal` (弹窗显示)
  * `renameWorkspaceId` (正在重命名的空间ID)
  * `renameWorkspaceType` (正在重命名的空间类型)
  * `renameInput` (重命名输入内容)
  * `renaming` (保存Loading状态)
* **API 交互**：
  * 调用已有的后端 `PATCH /api/workspace/update?workspaceId={id}` 接口。
  * 传入 `{ name: renameInput }`，更新成功后重置状态并调用 `loadUserInfo()` 刷新页面。

## 4. 任务清单 (Bite-Sized Tasks)
1. **声明状态与 API 方法**：在 `page.tsx` 中编写重命名弹窗状态与 `handleRenameWorkspace` 接口请求方法。
2. **集成弹窗 UI 渲染**：在 JSX 最外层追加磨砂玻璃感、高科技极客微光风格的 `RenameWorkspaceModal`。
3. **改造页面 Bento Grid 布局**：移除 Card 5（组件库）、Card 4（协作加入），精简 Card 1。将 Card 6 升级合并入右下侧 Card 4 综合统计。
4. **绑定空间项操作按钮**：在列表项追加编辑/重命名及分享按钮；限制企业空间 OWNER/ADMIN 权限；在 Card 3 底部引入虚线快捷加入。
5. **编译与自检**：运行 `npm run build` 全链路编译，确认无任何 TypeScript 报错，执行交互与留白自检。
