# 工作空间工作执行控制台重构与产品级优化需求文档

## 一、 页面定位与整体布局体系

在“知阁·舟坊”全栈平台中，`/workspace/[id]` 页面被明确定义为“空间工作控制台”。为了解决长页面滚动过深、功能大杂烩、模块职责模糊的痛点，页面外层与整体皮肤完全按照 `/workspace-hub`（空间中枢）的设计风格收敛统一，并采用 **“顶部固定区 + 主功能标签页 (Tabs) 切换 + 动态右侧上下文辅助栏”** 组成的标签页架构。

---

## 二、 横向标签页 (Tabs) 职责与模块设计

为了确立各模块的清晰职责，控制台数据在页签之间完全解耦分立：

### 1. 总览 (Overview)
- **新手操作引导**：系统自诊断当前空间状态，智能给出“第一步做什么”的强行动指引：
  - *空间无组件* ➔ 引导去组件大厅挑选装配；
  - *空间无任务记录* ➔ 引导创建首次分析任务；
  - *检测到任务处理失败* ➔ 引导点击重试或查看日志；
  - *有导入资料但无任务* ➔ 引导基于已有资料创建任务。
- **主路径入口**：提供材料自动匹配推荐、选择组件任务、继续未完成任务的 3 大快捷卡片。
- **大数字指标**：展示已装配组件数、执行中任务数、已生成报告数、归档团队规范数。
- **最近卡片摘要**：仅提取最近 3 个任务与最近使用组件，点击一键跳转至对应 Tab 查看全量列表。

### 2. 快速任务 (Quick Task)
- **步骤式流程**：将表单分为“选择组件”与“载入推荐匹配”子选项，指引更加精确。
- **条件拦截校验 (安全状态机)**：在执行任务按钮上方提供实时条件检查。若出现以下任意不满足，按钮禁用并显示红色/黄色原因：
  - *未选择组件* ➔ 提示“请先选择需要执行的效能组件”；
  - *未输入内容* ➔ 提示“请输入待处理的研发源材料”；
  - *岗位越权* ➔ 提示“当前企业岗位无权限执行此受限组件”；
  - *点数不足* ➔ 提示“当前空间服务调用点数不足，请升级或联系管理员”。

### 3. 已装组件 (Components)
- 提供已装配、推荐组件的子页签切换。
- 支持 10 大研发生命周期流转轴过滤，并明确标识组件状态（可执行、待配置、无权限、执行中）。

### 4. 历史任务 (Tasks)
- 全量自动化任务改写为更专业的历史记录表格，包含名称、关联组件、调用点数、状态及操作按钮，支持按全部/成功/失败过滤。

### 5. 空间资料 (Assets)
- 集中存储原始输入文件与使用材料，支持复用为任务输入源，与分析成果完全隔离。

### 6. 结果中心 (Results)
- 汇总成功的分析报告，提供结构化看板阅览、一键导出（Word/PDF/复制 Markdown）及归档入口。

### 7. 团队规范 (Knowledge Hub)
- 归档经过团队确认的 SOP 和经典案例。个人空间免审直接归档，企业协同空间提交后进入待审批列表。

### 8. 空间设置 (Settings)
- 集中进行空间更改名称、默认组件挑选、资料一键清理与重置沙盒（安全二次确认）。
- 企业协同空间下，在此集成成员、权限、统计与操作审计，并通过 RBAC 岗位机制做精细化卡口拦截。

## 三、 动态右侧上下文辅助栏 (Contextual Sidebar)

右侧栏根据当前选中的 Tab 状态进行深度联动与动态求值渲染：

| 当前主活动 Tab | 右侧辅助栏显示模块 |
| :--- | :--- |
| **总览** | 可用点数额度摘要警告条 + 快捷工具 + 待办提醒（任务数及结果数） |
| **快速任务** | 执行条件实时状态检查 + 点数预计消耗 + 支持格式 + 步骤指引帮助 |
| **组件** | 组件总数/受限/待配置状态统计 + 组件大厅跳转入口 |
| **任务** | 任务执行大盘统计 + 成功率指标 + 失败任务快速重试汇总面板 |
| **空间资料** | 存储空间 KB 占用条 + 最近上传文件列表 + 资料格式范围 |
| **结果中心** | 可导出成果数统计 + 待确认/已归档状态大纲 |
| **团队规范** | 已归档规范数统计 + 企业待审核申请大纲 + 规范类型简介 |
| **空间设置** | 当前用户的角色权限责任说明 + 高危操作提示 |

## 四、 编译、渲染与水合防御性研发规范

1. **客户端挂载锁死 (hasMounted)**：顶级�1. **主导航分立与高对比度路径高亮**：
   - **未登录访客（官网导航）**：配置为组件大厅、解决方案、私有化与安全、价格方案、文档中心；右侧显示“登录”与“免费体验工作台”；Logo 链接首页 `/`。
   - **已登录用户（工作导航）**：配置为空间中枢、组件大厅、任务中心、知识库、文档中心；右侧集成 `WorkspaceSwitcher` 空间切换器、通知图标与 `AvatarDropdown`；Logo 链接跳转 `/workspace-hub`。
   - **未登录点击拦截**：对需登录的路由加上跳转拦截，自动重定向至 `/auth/login?redirect=...`，确保认证闭环。
2. **账号头像下拉菜单（AvatarDropdown）重组**：
   - 分组一（账号）：个人中心、个人设置、账号安全。
   - 分组二（资源）：会员与额度、订单记录、API Key、Webhooks。
   - 分组三（其他）：帮助与支持文档、退出登录。
   - 分组四（企业管理）：根据企业空间身份参数，条件显现 “我管理的企业空间”、“企业成员管理” 与 “企业组件授权”。
   - 分组五（平台运营治理）：对 role 为 `admin`/`super_admin`/`platform_admin` 的高权限用户展示 “平台管理后台” 入口、“用户账号治理” 与 “组件库上架管理” 按钮。
3. **空间二级导航过滤白名单**：
   - **个人空间** ➔ 总览、快速任务、组件、任务、资料、结果、知识库、设置。
   - **企业普通成员** ➔ 总览、快速任务、组件、任务、资料、结果、知识库。
   - **企业管理员/Owner** ➔ 总览、快速任务、组件、任务、资料、结果、知识库、成员、权限、统计、日志 (`logs`)、设置。
   - **组件管理员/知识库管理员** ➔ 定制化显示组件配置、组件授权或知识审核等功能入口，并补齐了 `logs`（审计日志）的渲染分支。
4. **后台管理（/admin）越权阻断**：
   - 当非管理员请求进入平台后台时，系统直接原地捕获并渲染精心美化的 **403 访问受限** 警告页，提供“返回前台空间中枢”的入口，消除静默闪退与非法越权隐患。
5. **开发者文档升维文档中心与数据安全阻断**：
   - **文档中心定位**：顶部主导航重命名为“文档中心”，以容纳不同层级的业务及非技术访客；首屏重构为四大主导向卡片入口与 6 大精细目录。
   - **隐私隔离保护**：未登录用户绝对不可查看任何敏感数据（API Key、企业配置等），所有鉴权、Webhook 事件参数一律通过 MOCK（YOUR_API_KEY）进行无污染的安全占位呈现。
   - **已登录快捷通道**：登录用户在文档页面右上角无缝接入“我的开发者资源”独立快捷按钮组（我的 API Key、Webhooks 设置、沙箱测试、调用统计），满足日常运营与配置需要。）以及虚化渐变阴影。
   - 大名片头部与主体三栏容器必须显式叠加 `relative z-10` 浮动层级，以保持毛玻璃和圆角卡片的层次感与可交互性。
   - **核心操作按钮的 UI 规范打磨**：
     * *统一高亲和度圆角*：快速切换、开始新任务、挑选装配大厅、空间中枢等按钮一律抛弃硬圆角，升级为规范的 `rounded-lg` (8px) 圆角。
     * *视觉质感与描边*：严禁刺眼的硬黑描边。次要按钮采用知性蓝淡描边（`border-[#3182ce]/35 text-[#3182ce]`）与毛玻璃灰白底（`bg-slate-50 border-slate-200`），保证质感的高级度。
     * *悬停浮动动效*：交互按钮一律绑定 `hover:-translate-y-0.5 shadow-sm hover:shadow transition-all duration-200` 悬停动效，全面提升控制台的操作反馈与品质。
5. **去 AI 痕迹、字号升级与指引规范**：
   - **全站去 AI 语境**：抛弃 `Sparkles`（火花/AI）和 `Zap`（闪电/算力）等一切 AI 图标，替换为常规的 `Plus`、`Play`、`HelpCircle`、`Info` 等传统系统图标。将“算力额度/Token”更正为“可用调用点数”，将“仿真/编译”更正为“自动化任务处理”，将“知识库”更正为“团队规范库”，全面转译为成熟稳定的企业软件表述。
   - **字号统一底线**：禁止使用超小、模糊的 `text-[10px]`、`text-[11px]` 及 `text-[9px]` 蚂蚁字，中文字体最小以 `text-xs` (12px) 统一排版输出，根除排版拥挤感，提高无障碍阅读体验。
   - **业务场景引导说明**：各个功能 Tab 内必须提供浅显易懂的使用指南。如快速任务顶部的“使用三步走”、资料页的“上传免复制粘贴”说明，确保零技术背景用户也能迅速上手并形成业务闭环。

## 五、 2026-06-28 运行时 ReferenceError 修复与全站术语一致性对齐

1. **运行时崩溃故障修复**：补齐了控制台主布局 V3 容器中缺失的 `renderTabContent()` 方法及相关交互状态与依赖函数（`openStructurePreview`, `handleAIAssist`, `handleQuickStartSubmit` 等），彻底消除了控制台主页访问时抛出的 `ReferenceError: renderTabContent is not defined` 阻断性 Bug。
2. **术语与图标“去 AI 痕迹”修正**：
   - 将原版 Tab 中零散使用的 AI 风格图标进行了整体替换（如 `Sparkles` ➔ `Info`/`HelpCircle`，`Zap` ➔ `Play`，`CheckSquare` ➔ `CheckCircle2`，`BarChart3` ➔ `BarChart2`）。
   - 将主页面中所有的 “Token”、“算力”、“算力预计消耗” 升级替换为 “调用点数”、“可用点数” 及 “预计点数消耗”。
   - 将所有 “编译/仿真任务” 统一更正为符合企业级规范的 “自动化任务处理”。
3. **数据流与组件结构兼容性映射**：
   - 将原版大文件中的 `documents` 状态优雅映射到已解耦的 `assets`（输入资料库）与 `knowledges`（团队规范库），不引入冗余逻辑。
   - 为主控制台中的协同成员、权限矩阵、调用统计及空间设置提供了美观且对齐 V3 配色体系的重定向跳转与大纲说明。
4. **视觉排版重塑与层级梳理 (V6.0 升维)**：
   - 彻底梳理配色层级，大面积降低纯黑字体（`font-black` 及过深的 `text-slate-900`）的堆砌度，改用知性蓝与高质感中灰（`text-slate-800` / `text-slate-500`）形成高级灰度梯队。
   - 强制将主页面及 Modals 中因排版错乱导致的微小中文小字（9px-11px）升级为最低 `text-xs` (12px) 物理底线，避免渲染黏连。
   - 修复了 `renderRightPanel` 中由于拼接断层导致的语法错乱与卡片嵌套，将右侧面板中各 Tab 的说明面板、按钮尺寸、输入框高度重塑为具备大厂呼吸感的高端微毛玻璃交互卡片。
