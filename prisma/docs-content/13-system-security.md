# 平台运行与数据安全说明

本文仅陈述用户可感知与可验证的安全机制，供企业与团队评估使用。

## 账号与登录安全

- 密码以不可逆哈希存储；连续输错触发临时锁定。
- 会话具备空闲超时与绝对超时双重保护；勾选"7 天内免登录"后空闲保护豁免，仍受 7 天硬超时约束。
- 修改密码会强制所有设备重新登录；登录记录（时间、IP、设备）可在"账号安全"页查看，并支持远程下线设备。
- 高危操作（注销账号、删除空间、转让所有权等）需要二次密码验证。

## 数据归属与隔离

- 工作空间内的任务、成果与资料归属该空间；空间外用户（含游客）无法访问。
- 企业空间的组件执行权限由岗位权限矩阵控制，未授权组件对成员不可用。
- 删除空间或资料前有明确的状态检查与二次确认，操作全程写入审计日志。

## 密钥与敏感信息

- 用户自带模型的 API Key 以加密密文存储，页面仅回显掩码。
- 平台管理员与普通用户的数据可见范围严格分离。
- 操作日志支持按时间、类型检索，日志删除受合规约束（安全类日志用户本人不可删除）。

## 计费可核对

算力点的每一笔扣除、退款、充值均写入流水并附带余额快照，用户可在"我的点数"与账务中心逐笔核对。
