# 知识沉淀规范

## 定位与分工

- 知识库：沉淀文字类知识——项目规约、SOP、经验结论、组件使用心得。条目为纯文本 / Markdown。
- 资料：承载文件类材料（PDF、Word、Excel 等），在工作空间的"资料"页上传与管理。

需要归档文件时请使用"资料"功能；知识条目不保存附件。

## 条目写法

1. 标题写明对象与结论方向，如"登录模块接口设计规约"，避免"注意事项一"这类无信息量标题。
2. 正文用 Markdown 组织：先给结论，再列依据与步骤；涉及接口与参数时用表格。
3. 一条知识只讲一件事；相关内容用"相关条目"文字引用，不要复制粘贴成多篇。

## 分类与命名

- 分类使用空间内既有的知识分类，不要自创新分类名。
- 标题建议格式：[对象][动作/结论]，如「测试环境部署：最小步骤清单」。

## 维护

- 条目内容变化后直接编辑原文，平台保留编辑历史。
- 失效条目请更新或在正文中标注失效日期，避免误导后来者。
