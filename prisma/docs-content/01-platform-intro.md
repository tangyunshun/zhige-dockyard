# 平台介绍与核心概念

知阁·舟坊是面向研发团队的 AI 效能平台。平台将常见研发任务（标书解析、需求拆解、接口开发、测试体检等）封装为标准化的"数据契约组件"，用户选择组件、提交材料，平台按组件契约调用模型完成处理并交付结构化成果。

## 核心概念

| 概念 | 说明 |
| --- | --- |
| 组件 | 平台的能力单元。每个组件定义了输入材料、处理流程与输出成果，共 60 个，覆盖 10 个研发阶段。 |
| 数据契约 | 组件对输入与输出的约定：接受什么格式的材料、交付什么形式的成果。执行前请按契约准备材料。 |
| 工作空间 | 任务执行与资产归属的容器，分个人空间（单人）与企业空间（多人协作）。 |
| 算力点 | 平台统一计费单位，1 算力点 = 0.01 元。组件执行前按计费规则即时扣除。 |

## 组件与阶段

| 阶段 | 编号 | 典型能力 |
| --- | --- | --- |
| 商机捕获与售前打单 | C01-C06 | 标书解析、方案生成、偏离表 |
| 需求定义与产品设计 | C07-C10 | 需求拆解、PRD、原型设计 |
| 后端开发与接口 | C11-C16 | 接口设计、代码生成、契约校验 |
| 数据库设计与优化 | C17-C20 | 表结构设计、SQL 优化、索引建议 |
| 网页界面大前端 | C21-C25 | 页面与交互实现、组件代码 |
| 测试质量与安全体检 | C26-C30 | 用例生成、质量扫描、安全体检 |
| 环境打包与服务器运维 | C31-C35 | 构建、部署、运维脚本 |
| 安全防护与黑客拦截 | C36-C40 | 安全防护、风险拦截、加固建议 |
| 项目进度与工期排班 | C41-C45 | 排期、进度管理、风险预警 |
| 知识资产与文档说明书 | C46-C60 | 文档、知识沉淀、说明书生成 |

## 整体流程

1. 注册账号，系统自动创建个人空间。
2. 在组件大厅选择组件，装配到工作空间。
3. 按组件契约提交材料，发起执行。
4. 平台扣除算力点并调用模型处理；失败时全额原路退回。
5. 在结果页查看、复制或导出成果。
