# 算力管理：共享池与成员配额

## 共享池

企业空间的算力充值进入共享池，池内算力供空间内组件执行统一扣减。充值入口在空间算力页或账务中心，支持在线支付与对公转账。

## 成员额度分配

成员执行组件优先扣自己的独立额度，额度不足时提示改用共享池或个人钱包（由所有者在分配策略与执行确认中控制）。

分配操作：

1. 空间所有者或管理员进入"成员"页，找到目标成员。
2. 点击"配置算力"，输入额度数值并保存。
3. 系统将共享池中对应点数划入成员独立额度，写入双向流水（池出账、成员入账）。

回收操作：将成员额度改小，差额自动退回共享池。回收与分配均有流水记录，可在账务中心核对。

## 规则与限制

| 项目 | 规则 |
| --- | --- |
| 分配上限 | 不能超过共享池当前余额 |
| 回收 | 成员已消耗部分不回收，仅回收剩余额度 |
| OWNER/ADMIN | 不参与分配，直接使用共享池 |
| 低额预警 | 成员余额低于阈值时列表标黄，管理员可在空间设置调整阈值 |
