# 快速上手：从注册到第一个任务

## 前置条件

- 一个可接收短信验证码的手机号（注册用）。
- 执行组件会消耗算力点；新用户有注册赠送，详见《计费与算力点常见问题》。

## 操作步骤

### 第 1 步：注册并登录

打开注册页，输入手机号并完成短信验证码校验，设置密码后完成注册。注册成功后系统自动创建个人空间，并发放新用户算力赠送。

### 第 2 步：进入组件大厅

顶部导航点击"组件大厅"。大厅按 10 个应用阶段展示全部组件，支持按名称搜索、按分类筛选，也可在"智能匹配"中粘贴需求描述，由系统按关键词推荐组件。

### 第 3 步：选择并装配组件

点击目标组件卡片，确认组件的输入契约（接受什么材料）与输出说明，选择工作空间后点击"装配并使用"。装配会记入空间资产，可在空间的"组件"页查看与解除。

### 第 4 步：提交材料并执行

按契约上传文件或粘贴文本，确认估价后发起执行。执行前系统即时扣除算力点：个人空间先扣个人钱包，企业空间优先扣共享池（成员额度不足时可改用个人钱包支付，见执行确认弹窗）。

### 第 5 步：查看结果

执行完成后在结果页查看成果，支持复制、导出 Markdown 与 Word。执行失败时已扣算力点全额原路退回，可在"我的点数"查看流水。

## 常见问题

- 组件点击提示"岗位受限"：企业空间配置了岗位权限矩阵，请联系空间管理员调整。
- 执行失败：先核对材料是否符合契约，再确认余额与模型可用性，详见《常见故障排查》。
