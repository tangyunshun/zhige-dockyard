# 空间安全：转让、解散与数据清理

## 所有权转让

适用场景：所有者离职、岗位交接，空间需要继续运营。

条件与规则：

- 仅企业空间支持转让；受让人必须是本空间的在册管理员。
- 全程需要所有者完成二次密码验证。
- 转让后：原所有者降为管理员，保留全部可见范围；受让人成为所有者。
- 账务交接：共享池留在空间不动；受让人名下的成员独立额度自动退回共享池，避免重复计账。
- 转让操作记录审计日志。

操作入口：空间"成员"页 → 目标管理员所在行 → "转让所有权" → 输入空间名称确认 → 完成二次验证。

## 重置空间数据

"重置空间数据"清空空间内任务历史、成果与资料。个人空间重置后自动恢复 5 个出厂默认组件；企业空间重置不恢复。该操作不可逆，执行前需要确认输入空间名称。

## 停用与解散

- 企业空间：所有者可在设置页"停用空间"，停用后空间进入只读，成员不可再执行任务。删除前需先停用。
- 个人空间：在空间中枢发起注销，需通过资产检查（有未完成任务或已绑定组件时先处理）。
- 两种操作均需二次密码验证，且会清除登录态。
