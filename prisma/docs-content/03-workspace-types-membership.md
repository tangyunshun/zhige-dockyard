# 工作空间类型与会员权益

## 两种空间类型

| 项目 | 个人空间 | 企业空间 |
| --- | --- | --- |
| 成员 | 仅本人，不支持协作 | 支持邀请成员、岗位权限、算力分配 |
| 算力 | 个人钱包 + 空间赠送 | 共享算力池 + 成员独立额度 |
| 创建 | 注册后自动创建 | 由个人空间升级，或新建时选择 |
| 解散 | 可注销（需通过空间中枢） | 可停用，支持所有权转让 |

升级入口：空间中枢 → 目标个人空间 → "升级为企业空间"，按引导选择套餐并完成支付。升级后原空间资料保留。

## 会员等级

会员等级由低到高：免费版、青铜、白银、黄金、钻石、皇冠，另有企业专享会员。等级影响：

- 可拥有的企业空间数量。
- 空间席位与额度上限。
- 部分功能的配额。

各等级的具体权益数值以会员中心页面实时展示为准，此处不逐一列举。等级随套餐购买与续费变更，到期未续费按规则降级。

## 空间套餐

企业空间按套餐计费（月付/年付），套餐决定席位数量、组件配额与有效期。套餐到期未续费，空间降级为免费版权益，已有资料保留但超出免费权益的部分（如超额席位）停止扩容。
