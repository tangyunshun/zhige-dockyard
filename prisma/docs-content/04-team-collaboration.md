# 团队协作：邀请、角色与岗位权限

## 邀请成员

1. 空间所有者或管理员进入空间"成员"页，点击"生成邀请码"。
2. 将邀请码或邀请链接发给被邀请人。
3. 对方登录后在空间中枢输入邀请码完成加入。

规则：

- 每个用户最多加入 5 个企业空间；空间席位已满时无法加入（席位 = 套餐席位 + 增购）。
- 邀请码默认 7 天有效，可随时作废或删除；作废后立即失效。
- 可在生成时指定加入后的角色（成员或管理员）。

## 角色与权限

| 能力 | 所有者 OWNER | 管理员 ADMIN | 成员 MEMBER |
| --- | --- | --- | --- |
| 修改空间信息 | 是 | 是 | 否 |
| 生成/作废邀请码 | 是 | 是 | 否 |
| 移除成员 | 是 | 是（不能移除管理员） | 否 |
| 修改成员角色 | 是 | 否 | 否 |
| 分配成员算力 | 是 | 是 | 否 |
| 转让所有权 | 是 | 否 | 否 |
| 停用/解散空间 | 是 | 否 | 否 |

所有者不可被移除或自行退出；如需离开空间，先转让所有权或解散空间。

## 岗位权限矩阵

企业空间可创建岗位（如研发工程师、测试工程师），并为每个岗位勾选可执行的组件。成员被指派岗位后：

- 成员只能执行岗位允许的组件，其余组件在组件大厅与执行入口均显示"岗位受限"。
- 未指派任何岗位的成员，在权限矩阵启用后默认无法执行组件。
- 所有者与管理员不受岗位限制。

## 成员退出与移除

- 成员可自行退出空间。
- 管理员可在成员页移除普通成员；移除后其成员独立额度按原路退回共享池。
- 被移除的用户会在下次访问时收到通知并被引导退出。
